# 🎬 Movie Data Analysis

## 📌 Project Overview

This project analyzes movie data to understand patterns based on **genre, IMDb rating, release year, runtime, and revenue**.

The project uses Python and Pandas for data analysis and Matplotlib/Seaborn for visualization.

The main objective is to clean the movie dataset, perform genre-based analysis, and visualize important movie trends.

---

## 🎯 Objectives

* Analyze the number of movies in each genre.
* Calculate the average IMDb rating for each genre.
* Calculate the average revenue for each genre.
* Handle missing and invalid values in the dataset.
* Analyze movies released across different years.
* Visualize the distribution of IMDb ratings.
* Visualize genre-wise average ratings and revenue.
